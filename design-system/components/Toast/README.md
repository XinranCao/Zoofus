Toast is a small flat torn note with one piece of tape.

**Kinds.** Success uses `celery-200`, a moss check and `role="status"`. Error uses `blush-100`, a raspberry alert, a plum title and `role="alert"`. Info uses `cream-100`.

**Anatomy.** An icon, a title (Special Elite 15px), one line of body (`body-sm`) and an optional quiet action ("Undo"). Max 340px, `md` tear, ±0.8°.

**Behaviour.** Radix Toast, bottom-centre on mobile and bottom-right on desktop. Success lasts 4s and an error stays until dismissed. Never stack more than 3.
