AvatarMenu is the account dropdown that opens from the masthead avatar.

**Anatomy.** A flat `scrap` Paper (`md` tear with lip) holding the name (`h2` 17px), the email (`ink-muted`), a dashed divider, then items: My sticker book, Profile, Log out. Each item has an 18px icon and a `label`. The highlighted item uses `selected` with its own small torn clip.

**Behaviour.** Radix DropdownMenu, arrow keys, typeahead.
