Collage is a loose cluster of die-cut stickers, the only "image" on a page (empty states, the log in page, the landing).

**Anatomy.** Stickers at `rot-sticker` (±4°) in a wrapping flex row, `aria-hidden`. It is decoration: it never carries information, and it must never push the first action off the first screen.

**Rules.** Stickers only, no stock illustration. No shadow.
