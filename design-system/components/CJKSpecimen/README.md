CJKSpecimen is a live comparison of Chinese faces set beside Special Elite and Courier Prime, used to choose the CJK pairing.

**Candidates.**
1. **Xiaolai Mono SC (小赖字体 等宽)**, the default: monospaced, loose hand-written strokes. `cn-fontsource-xiaolai-mono-sc-regular`, OFL.
2. **LXGW Marker Gothic (霞鹜漫黑)**, an alternative for headings: chunky felt-marker gothic. `@fontsource/lxgw-marker-gothic`, OFL.
3. **LXGW WenKai (霞鹜文楷)**, the calm option: semi-handwritten kai. `@fontsource/lxgw-wenkai`, OFL.

Each row shows a heading, a label and body pairs, plus whether the face loaded in your browser (from jsDelivr). If a row says "not loaded here", you are seeing the fallback font.
