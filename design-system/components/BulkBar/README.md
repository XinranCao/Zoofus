BulkBar appears at the bottom of the screen while a person is picking many things: how many are picked, Select all / None, the actions that apply, and Done.

**Anatomy.** A full-width `scrap-warm` torn strip (`sm` tear, 0.3° tilt) in a `role="region"`. The count is a polite `role="status"`. Actions are small buttons (Add to collection, Share, Delete, each disabled until something is picked); Done is the only button with a check icon and is secondary, not brick.

**Rules.** One bar per screen. It sits above the page's content with room left under the last tile, so nothing is hidden behind it. Delete asks for confirmation.
