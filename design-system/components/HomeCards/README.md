HomeCards are the scraps on the signed-in home: Continue, Waiting, the four things to try, the idea of the day, and the "Try next" strip.

- **ContinueCard.** `lg` scrap with two tapes: the last journal's page picture, "Pick up where you left off", its title, "Edited yesterday", the primary "Continue" and a secondary "New sticker".
- **WaitingCard.** `scrap-cool`, one tape: "{n} things are waiting for you", up to three rows with one button each (Accept, Take a look, Join).
- **PathCards.** Four scraps (Cut a sticker, Make a tape, Fill a journal page, Add a friend). A stamp (an SVG oval with hand lettering, never a border-radius) reads "Start here" on the first not done and "Done" on the others.
- **IdeaCard.** `scrap-warm`, one tape: one sentence that starts with a making verb, and "Another idea".
- **NextStrip.** A sheet strip that points to the first unused feature; hidden when all are used.

**Rules.** One brick button per view. Skeletons keep the cards' size while data loads. No streaks, no counters, no guilt.
