SaveStatus is the one plain line that says where a journal stands: "Saved", "Saving…" or "Not saved yet".

**Anatomy.** Text only (`caption`, `ink-muted` on light scraps) in a `role="status"` polite live region. The journal studio and Together share it.

**Rules.** It never opens a dialog and never takes focus. It sits in the top bar's one row and must not change the row's height or wrap when its text changes (on a phone the row would push the page down).
