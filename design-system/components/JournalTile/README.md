JournalTile is one journal in a list: the page's picture on a small `sheet-50` scrap with the title above and the date below.

**Anatomy.** The title above, a torn `sheet-50` face (about 180px wide, `rot` ~1.2°) holding the page picture (a WebP of the page), the date in `caption`; tape on about one tile in three. The same actions as every library tile (Rename, Share, Add to a collection, Delete), on hover or focus-within and always on touch.

**States.** A journal without a picture yet is drawn from its items (the first six tiles of a list only), and if it has no items it shows its paper. The tile never shows a blank face. Select mode adds a `SelectMark`.
