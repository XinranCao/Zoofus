PageHeader is the top of a page: the title, an optional line under it, the page's own actions on the right, and a small die-cut sticker beside the title.

**Anatomy.** A `h1` in `display` (Special Elite), a `lead` line in body, an actions row (at most one primary), and one sticker art that suits the page (decoration only, `aria-hidden`).

**Rules.** The title starts in the same place on every page, so it does not jump between pages; focus moves to this `h1` after a route change.
